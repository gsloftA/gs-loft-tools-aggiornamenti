# GS LOFT Tools · canale aggiornamenti

Le app GS LOFT Tools leggono `canale.json` per sapere se c'è un aggiornamento.

Ogni canale è firmato: le app installano solo pacchetti firmati con la chiave di GS LOFT.

Le **Issues** con etichetta `feedback` sono le idee del team inviate dall'app.

Per cambiare lo stato di un'idea usa le etichette `in-valutazione`, `in-sviluppo`, `realizzato`, `non-previsto`.

Un commento scritto qui compare nell'app come risposta ufficiale di GS LOFT.
